# Eco Vibes Safari – Website

Modern, responsive tourism website for **Eco Vibes Safari**, a Tanzania-based safari and trekking company based in Arusha.

## Features

- **Full structure**: Home, About Us, Destinations, Tours, Accommodation, Services, Gallery, Blog, FAQ, Contact
- **Destinations covered**: Serengeti, Ngorongoro, Tarangire, Arusha National Park, Mikumi, Mount Kilimanjaro, Mount Meru + Arusha attractions
- **Services**: Safari trips, Hiking/Trekking, Transport (4x4), Food (including cultural cuisine), Accommodation options
- **Language switch**: English ↔ Swahili (button top-right)
- **Floating WhatsApp button** (right side)
- **Social media icons** (Facebook, Instagram, X, YouTube, TripAdvisor)
- **Tourism color scheme**: Deep forest green + Safari orange + Earth tones
- **Fully responsive** (mobile, tablet, desktop)
- **Modern UI**: Smooth animations, FAQ accordion, sticky header

## How to View

1. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge)
2. Or serve with a local server:
   ```bash
   # Python
   python -m http.server 8000

   # Node
   npx serve .
   ```
3. Then open http://localhost:8000

## Customization Tips

- **WhatsApp number**: Edit the link in `index.html` → search for `wa.me/255700000000` and replace with your real number
- **Phone & Email**: Search for `+255 7XX XXX XXX` and `info@ecovibessafari.com`
- **Images**: Currently using Unsplash placeholders. Replace with your own high-quality safari photos
- **Prices**: Update the package prices in the Tours section
- **Social links**: Add your real Facebook, Instagram, etc. URLs

## Tech Stack

- Pure HTML5 + CSS3 + Vanilla JavaScript
- Font Awesome 6 icons
- Google Fonts (Playfair Display + Poppins)
- No frameworks required
