HOW TO USE
----------
1. Open eco-vibe-safari.html in a browser.
2. Keep maasai.mp4 and leopard.mp4 in the SAME folder as the HTML so the
   hero videos play. If the videos are missing, the posters/photos still show.
3. Click any Unsplash link above, then use the download button on Unsplash
   for the original file, or save the direct 2400px URL.
