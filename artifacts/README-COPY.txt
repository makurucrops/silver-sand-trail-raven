ECO VIBE SAFARI — website copy
================================

Ndani ya folder hii kuna msimbo kamili wa website.

JINSI YA KUTUMIA
----------------
1. Extract (fungua) zip hii kwenye kompyuta yako.
2. Weka folder "Eco-Vibe-Safari" mahali unapotaka.
3. Ikiwa una Node.js:
     npm install
     npm run dev
   Website itafunguka kwenye browser.

------------

  public/logo.png      logo ya kampuni
